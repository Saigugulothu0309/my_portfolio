// 04. Projects

Things I've built

PROJECT_01

CyberShield

AI-powered cyber threat detection platform that analyzes URLs, QR codes, and images to identify phishing attacks. Combines trained ML models, domain intelligence, and third-party threat APIs into a single risk-scoring engine with a scan history dashboard.

Stack: Python · Flask · Scikit-learn · VirusTotal API · WHOIS · IP Lookup · SQLite · HTML/JS/Jinja

Pipeline: URL / QR / image submitted → feature extraction → ML phishing classifier → WHOIS + IP geolocation → VirusTotal reputation check → risk score → dashboard + SQLite history log.

PROJECT_02

Smart Network Logger

Passive network monitor that captures live packet traffic, engineers flow-level features, and detects anomalies using unsupervised ML — no labeled data required. Built for local network threat discovery with a real-time Streamlit dashboard.

Stack: Python · Scapy · Pandas · Scikit-learn (Isolation Forest) · Streamlit

Pipeline: Scapy captures live packets → Pandas extracts flow-level features (bytes/sec, packet intervals, protocol ratios) → Isolation Forest scores anomalies → Streamlit shows real-time threat feed with configurable severity thresholds.

PROJECT_03 IN PROGRESS

DualTalk

Real-time communication bridge between deaf and hearing users. Translates sign language gestures into text and speech, and converts spoken language back into visual output — enabling natural conversation without a human interpreter.

Planned stack: Python · MediaPipe · OpenCV · gTTS · Custom gesture dataset

Status: Actively in development. Core gesture recognition pipeline is being built and trained on a self-collected dataset. Bidirectional speech-to-sign output planned next.
