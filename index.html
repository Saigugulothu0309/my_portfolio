// 04. Projects

Things I've built

PROJECT_01

CyberShield

AI-powered cyber threat detection platform that analyzes URLs, QR codes, and images to identify phishing attacks. It combines machine learning, domain intelligence, and threat APIs into a practical risk-scoring workflow.

Stack: Python · Flask · Scikit-learn · VirusTotal API · WHOIS · IP Lookup · SQLite · HTML/JS/Jinja

Pipeline: URL / QR / image submitted → feature extraction → ML phishing classifier → WHOIS + IP geolocation → VirusTotal reputation check → risk score → dashboard + SQLite history log.
ML ClassificationPhishing Detection QR ScanningSteganography VirusTotalFlaskSQLite
GitHub Repository
PROJECT_02

Smart Network Logger

Passive network monitor that captures live packet traffic, engineers flow-level features, and detects anomalies using unsupervised ML with a real-time visual dashboard.

Stack: Python · Scapy · Pandas · Scikit-learn (Isolation Forest) · Streamlit

Pipeline: Scapy captures live packets → Pandas extracts flow-level features (bytes/sec, packet intervals, protocol ratios) → Isolation Forest scores anomalies → Streamlit shows real-time threat feed with configurable severity thresholds.
Anomaly DetectionIsolation Forest ScapyPandasStreamlitUnsupervised ML
GitHub Repository
